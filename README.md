# Latitude 53

Versão pública do roteiro, mapa e guia de Gustavo e Priscila, da Bahia para a Irlanda.

Site: https://gustavowaltrick.github.io/latitude-53/

Atualizado automaticamente todo dia às 20h (Bahia) a partir do site privado no Claude.
Custos, reservas, checklists e roteiro de gravação nunca são publicados aqui.

- `data.js`: dados públicos, gerado por `build/build.py`. Não edite à mão.
- `sw.js`: deixa o site funcionar offline no celular. A versão muda a cada atualização.
